# حسابداری و مالیات

پیاده‌سازی فعلی این قابلیت در این پوشه است. مسیرهای قدیمی لینک نسبی به همین کد هستند؛ نسخهٔ قابل ویرایش دیگری ساخته نشده است.

- `module.json`: مالکیت فایل‌ها، وابستگی و قرارداد دسترسی.
- `server/`: موتور و مسیرهای متعلق به قابلیت؛ ثبت مسیرها از ترکیب مرکزی انجام می‌شود.
- `frontend/`: همان دارایی‌ها و نماهای موجود؛ بدون بازطراحی.
- `releases/1.0.0`: خروجی ثابت رابط سازگار با API مشترک `westo-v1`.

خرید قابلیت فقط دسترسی مشتری را باز می‌کند؛ ثبت دادهٔ پایه و نگهداری سابقه به آن وابسته نیست. 0 مسیر از ورودی مرکزی و 3 نمای ادمین به این ماژول منتقل شده‌اند؛ مسیرهای موتورهای مستقل در فایل خودشان ثبت می‌شوند.
