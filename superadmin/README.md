# SALSA Super Admin & Control Plane Module (`superadmin/`)

این ماژول، مرکز فرماندهی پلتفرم و مدیریت کلان سیستم‌عامل رستورانی سالسا (SALSA Control Plane) است که به‌صورت کاملاً مستقل، ماژولار و تفکیک‌شده از محیط عملیاتی رستوران (WESTO) عمل می‌کند.

---

## 🚀 دستورات اجرا

### راه‌اندازی فرانت‌اند کنترل‌پنل (پورت ۳۰۵۰):
```bash
npm run start:superadmin
# یا با دستور قدیمی:
npm run start:godmode
```
آدرس دسترسی در مرورگر: `http://localhost:3050`؛ همین نام میزبان را برای جلوگیری از ناسازگاری کوکی نشست با `localhost:3061` حفظ کنید.

برای ورود توسعهٔ محلی، فرانت‌اند و Control Plane را در دو ترمینال جداگانه و صریحاً در حالت توسعه اجرا کنید. این حالت فقط نشست توسعه را فعال می‌کند؛ دادهٔ نمایشی در رابط مدیریت فعال نمی‌شود. `SALSA_SESSION_SECRET` باید در محیط توسعه تنظیم شده باشد:
```bash
npm run superadmin:control:dev
npm run start:superadmin:dev
```
در production از این دو دستور توسعه استفاده نکنید؛ دکمهٔ ورود توسعه فقط وقتی `NODE_ENV=development` است نمایش داده می‌شود و API نیز در production مستقل از رابط آن را رد می‌کند.

### راه‌اندازی بک‌اند کنترل‌پلن (پورت ۳۰۶۱):
```bash
npm run superadmin:control
# یا با دستور قدیمی:
npm run control:start
```
آدرس سلامت: `http://127.0.0.1:3061/api/control/health`

### اجرای تست‌های جامع خودکار:
```bash
npm run test:superadmin
# خروجی: ۴۳ تست موفق و ۰ ناموفق
```
